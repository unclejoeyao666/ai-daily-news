# GitHub Copilot 计费变革引发开发者愤怒

微软宣布自 2026 年 6 月 1 日起，GitHub Copilot 将从固定月费制转为按 Token 消耗计费。

## 价格暴涨
多位开发者在 Reddit 上晒出惊人账单：月费从 29 美元暴涨至 750 美元，甚至有截图显示费用从 50 美元飙升至 3000 美元。有用户直言「这定价模型荒谬至极」，并表示将取消订阅。

## 双方论战
支持者认为，「真正懂行的开发者」不会消耗这么多 Token，花费暴涨的用户多半是「边 vibe coding 边疯狂迭代」。反对者则指出，微软此前一直在鼓励用户无限制使用，现在突然改变规则是在「釜底抽薪」。

## 财务隐情
这场争论也引发了对 Copilot 本身盈利能力的质疑——有开发者发帖直问：「Copilot 之前到底亏了多少钱？」

## 对 AI 行业的影响

# 对 AI 行业的影响

GitHub Copilot 的计费变革是 AI 编程助手行业从「圈地」到「收割」的标志性转折。微软率先打破固定订阅模式，将迫使整个行业重新思考定价逻辑。

对于独立开发者和中小团队，AI 编程成本将变得更加不可预测。对于大企业虽有议价能力，但预算管理也将复杂化。这场变革可能加速开发者对本地模型和开源替代方案的探索。

更重要的是，它揭示了 AI 产品的根本矛盾：想让用户尽情使用以训练和改进模型，又想在用户产生依赖后实现盈利——这个平衡点远未达到。
