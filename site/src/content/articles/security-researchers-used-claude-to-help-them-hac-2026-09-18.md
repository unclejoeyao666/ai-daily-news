据 The Verge 引述《华尔街日报》报道，Hacktron 的三名独立安全研究人员称，他们使用 Anthropic 的 Claude Opus 4.8 和 5，在不到72小时内入侵了 OpenAI 员工账户，并访问了 OpenAI 的 GitHub 代码仓库 Monorepo。报道称该仓库包含 OpenAI 的算法机密。现有摘要未说明 OpenAI 是否确认全部细节。

## 对 AI 行业的影响

若相关说法得到确认，AI 模型将成为从账户接管到代码访问的攻击链加速器，而不只是信息检索工具。企业需要把模型滥用能力纳入红队测试，并强化员工身份认证、代码仓库权限和敏感资产分区；模型供应商也将面临更高的安全评估与责任压力。
