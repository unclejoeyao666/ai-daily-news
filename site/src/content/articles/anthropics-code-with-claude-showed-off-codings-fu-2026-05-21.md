Anthropic 近日在伦敦举办了首届 Code with Claude 大会，汇集全球软件开发者，展示 Claude 在编程辅助领域的最新能力。这场为期两天的活动与 Google I/O 在硅谷同步举行，Anthropic 员工强调纯属时间上的巧合而非刻意「秀肌肉」。

大会上，Anthropic 技术团队分享了公司在 AI 编程工具上的最新进展，包括多文件上下文理解、自主错误修复以及代码审查辅助等能力。大会的一个核心主题是「AI 编程助手如何改变软件开发的工作流」。

Anthropic 联合创始人 Amodei 在会上提出了一个大胆愿景：让 Claude 最终能够「自主构建自身」。这一目标意味着 AI 系统将在编程能力上实现递归式提升。

然而，会外也有不同声音。随着 AI 编程工具被企业管理者广泛推广以提升开发效率，部分开发者开始在 Reddit 和 Hacker News 等平台吐槽：AI 生成代码带来的额外审查工作量正在抵消其效率收益，有开发者直言：「说生成代码没问题的人，都是那些根本不读代码的人。」此外，研究人员也警告，AI 工具可能产生存在安全漏洞的代码，长期来看可能增加软件系统的攻击面。

## 对 AI 行业的影响

Code with Claude 是 Anthropic 面向开发者社区的一次重要品牌与技术展示，其「AI 编程助手」定位正在从工具向平台演进。但开发者社区对 AI 编程辅助的真实评价正在出现分化——效率提升与质量风险之间的张力，是整个行业都需要正视的结构性问题。对 Anthropic 而言，这场大会的意义不仅在于展示能力，更在于建立开发生态的系统性信任。
