Anthropic 表示，Claude Code 很快将默认启用自动模式。现有信息显示，这一变化旨在让使用 Claude Code 编程时减少人工监督，但未提供具体的上线时间、权限范围或安全限制细节。

## 对 AI 行业的影响

这会把更多编程步骤交给 AI 代理自动执行，降低开发者的操作成本，但也会提高权限控制、代码审查和错误回滚的重要性。对开发团队而言，自动化收益能否兑现，取决于现有测试与审批机制是否能覆盖更少人工介入的工作流。
