第一条。Snowflake 与 AWS 签署六十亿美元 AI 芯片大单。云数据巨头 Snowflake 与 AWS 签订了一份为期五年、价值六十亿美元的新协议，主要用于获取 AWS 自研的 ARM 架构芯片 Graviton。随着 AI 从模型训练走向日常推理和 agent 自动化，CPU 的算力需求正在激增。这笔交易的金额接近 Snowflake 自成立以来在 AWS Marketplace 上的历史累计销售额，也给 Nvidia 发出了明确信号——云计算巨头的自研芯片正在快速蚕食其市场份额。AWS 还曾在上个月与 Meta 签署了数百万颗 Graviton 芯片的供应协议，自研芯片已经成为整个行业的大趋势。

第二条。Meta 全球推出 Instagram、Facebook 和 WhatsApp 付费订阅计划。Meta 正式在全球范围内推出了 Plus 系列的订阅服务，Instagram Plus 和 Facebook Plus 月费三点九九美元，WhatsApp Plus 月费二点九九美元，订阅用户可以享受自定义应用图标、超级动画反应和故事观看数据分析等增值功能。与此同时，Meta 还开始测试更高层级的 Meta One 品牌订阅计划，包括针对 AI 用户的 Meta One Plus 和 Meta One Premium，以及面向创作者和企业的专业订阅方案。这意味着 Meta 正在从纯广告收入模式向混合变现模式进行深度转型。

第三条。AI 编程创企 Cognition 融资十亿美元，估值达到二百五十亿美元。Cognition 是 AI 编程助手 Devin 的开发商，刚刚完成了一轮超过十亿美元的融资，由 Lux Capital 和 General Catalyst 领投，投前估值达到二百五十亿美元，相比于八个月前的一百零二亿美元估值翻了一倍多。公司声称年化收入已达四亿九千二百万美元，企业客户包括 Mercedes-Benz、NASA 和 Goldman Sachs。这笔巨额融资说明顶级风投仍然相信在 Anthropic 和 OpenAI 等大模型厂商的竞争中，独立 AI 编程公司依然有巨大发展空间。

第四条。Robinhood 正式上线 AI agent 自动交易股票功能。用户可以为自己的 AI agent 创建独立的钱包账户，授权 agent 分析投资组合、制定交易策略并自动下单。agent 只能使用预存在专属钱包中的余额进行交易，每笔操作都会推送通知给用户，部分高风险交易需要用户预先审批。Robinhood 同时推出了 AI agent 专用的虚拟信用卡。目前仅支持股票交易，未来将扩展到期权、加密货币和期货。Stripe、Amazon 和 Google 也在构建类似的 agent 支付服务，金融领域的 agent 化浪潮正在加速到来。

第五条。OpenAI 和 Anthropic 的政治广告意外捧红了对手。由 OpenAI 资助的超级 PAC Leading the Future，自去年十二月起在纽约第十二选区的民主党初选中投入约二百四十万美元，持续投放负面广告攻击候选人 Alex Bores，后者曾起草美国首批 AI 监管法案。然而这种外部攻击反而触发了斯特赖桑德效应，让原本默默无闻的 Bores 在八人竞争中强势崛起，成为纽约曼哈顿选区最受关注的候选人之一。这个案例展示了 AI 巨头在政治博弈中的双刃剑效应。

第六条。网站有了新的追踪手段——通过浏览器测量你的 SSD 活动。安全研究人员公布了一种名为 FROST 的新型追踪技术，利用浏览器中的 JavaScript 与 OPFS 文件系统交互，测量用户固态硬盘的输入输出操作延迟，再通过预训练的卷积神经网络模型进行分析，就能推断出用户设备上打开的其他网站和应用程序。整个攻击过程不需要用户的任何交互。该攻击在 M2 Mac 上完成了完整验证。目前虽然没有野外利用证据，但这提醒我们浏览器在演变为操作系统级别平台的过程中，隐私风险也在不断增加。

第七条。薪资服务商 Remote 通过 AI 实现了人均营收增长百分之五十。这家总部在荷兰的初创公司宣布年经常性收入突破三亿美元，并且实现了正向现金流。CEO 透露公司超百分之八十五的代码由 AI 编写，工程师贡献量同比增长超过百分之六十，在不增加员工数量的前提下人均营收增长了一半。公司还推出了 Remote MCP 接口，允许 AI agent 直接访问薪资和合规数据。Remote 的实践为 AI 在企业效率方面的实际影响提供了罕见的量化数据。

第八条。你的 SEO 策略优化的搜索引擎已经不存在了。Google I/O 大会正式确认 AI 生成的答案已经成为搜索结果的默认展示方式，传统的十条蓝色链接模式面临根本性失效。绝大多数品牌几乎没有任何手段了解 AI 如何向它们的潜在客户描述自己的品牌。价值数百亿美元的 SEO 行业需要彻底重构，企业需要从争夺关键词排名转向争夺 AI 摘要中的引用权。AI 搜索正在对内容电商、媒体和信息型 SaaS 的获客模型构成系统性威胁。

第九条。ElevenLabs 新音乐模型可在曲中切换音乐风格。ElevenLabs 发布 Music v2 音乐生成模型，核心亮点是能够在歌曲中间自由切换风格，比如从古典音乐直接过渡到重金属再转回来。艺术家还可以分段构建歌曲，用提示词重新生成特定段落而不影响其他部分。模型基于授权数据训练，可以直接商用。相比之下，竞争对手 Suno 和 Udio 正面临着唱片公司的版权侵权诉讼，版权合规策略正在成为 AI 音乐公司的核心竞争壁垒。

第十条。Startup Battlefield 200 申请于今日截止。TechCrunch Disrupt 的 Startup Battlefield 200 申请通道于太平洋时间今晚十一点五十九分关闭。入选初创公司将在上万名观众面前展示自己的产品，并有机会角逐十万美元的无股权奖金。历史上这一赛事已经走出了 Dropbox、Cloudflare、Discord 和 Fitbit 等明星公司，超过一千七百家参与企业累计融资超过三百二十亿美元。即使是在 AI 融资热潮中，这样的平台仍是早期创业者获得媒体和投资人关注的高效渠道。
