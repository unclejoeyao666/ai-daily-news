早上好，欢迎收听 A I 科技每日早报。今天是二零二六年七月一日，星期三。今天为您播报十条值得关注的全球 A I 科技动态。

第一条。Claude Sonnet 五降低智能体成本。Anthropic 发布新的中端模型，把更强的规划、工具调用、代码能力和知识工作能力下放到更便宜的产品层。它的目标不是取代 Opus 四点八，而是让企业和个人在日常智能体任务里少用昂贵模型。限时价格是每百万输入 tokens 两美元、每百万输出 tokens 十美元，八月底后会提高。关键变化是，agent 能力正在成为基础配置，竞争焦点从谁最强，转向谁能以更低成本稳定完成真实工作。

第二条。美国解除 Anthropic 模型出口限制。美国政府取消了 Mythos 和 Fable 模型的出口许可要求，Anthropic 将从七月一日起恢复访问。此前限制让这两个先进模型几乎无法公开提供，因为按国籍逐一审批在实际服务中不可执行。政府称 Anthropic 同意主动识别安全风险、配合制定发布协议并通报恶意活动。这件事说明，前沿模型发布已经进入政策、安全和国际竞争交织的新阶段，OpenAI、Google 与 Anthropic 都会受到更强监管压力。

第三条。Google 发布新图像与视频模型。Google DeepMind 推出 Nano Banana 二 Lite 和 Gemini Omni Flash。前者主打快速、低成本图像生成，适合高吞吐视觉工作流；后者面向开发者开放视频生成和自然语言视频编辑。Nano Banana 二 Lite 已进入 Google AI Studio、Gemini API 和多个消费产品，Omni Flash 则以预览形式支持多模态输入。Google 的意图很清楚，把图像、视频和应用入口连成一条开发链路，压缩独立生成式媒体工具的空间。

第四条。Claude Science 瞄准科研工作流。Anthropic 推出 Claude Science，一个为科学家设计的 A I 工作台。它不是新模型，而是把 Claude、科研数据库、专业工具包、子助手和事实核查放进同一环境，减少研究人员在数据、代码和实验流程之间反复切换。它可连接六十多个科学数据库，覆盖基因组学、蛋白结构和化学等领域。Anthropic 正在复制 Claude Code 的路线，把模型能力变成具体行业的操作层。

第五条。Anthropic 将科研产品升为旗舰。MIT Technology Review 把 Claude Science 解读为 Anthropic 的核心战略产品，地位接近 Claude Code 和 Claude Cowork。公司不仅向付费用户开放，还计划用它推进罕见病和被忽视疾病的药物候选研究。这里的商业意义很强：制药公司资金充足，科研工作流又高度依赖工具、代码和可复现结果。如果 Anthropic 能拿下药企客户，就能在 IPO 叙事之外证明企业级收入质量。

第六条。Wayve 以八十五亿美元估值回购员工股。英国自动驾驶 A I 公司 Wayve 发起八千五百万美元员工股权流动性计划，让员工出售部分已归属股权。这是越来越多 A I 独角兽采用的留才方式，在上市和并购窗口不确定时，先给员工部分兑现机会。Wayve 采用端到端神经网络路线，不依赖传统高清地图，并计划今年与 Uber 推出 robotaxi 试点，二零二七年进入 Nissan 的下一代驾驶辅助系统。

第七条。AWS 组建十亿美元 A I F D E 团队。Amazon Web Services 推出新的前线部署工程师组织，把工程师派驻客户内部，帮助企业快速部署定制化智能体。这个模式由 Palantir 推广，最近 OpenAI 和 Anthropic 也在跟进。它反映了企业 A I 的真正瓶颈：买模型并不难，难的是把模型嵌进业务流程、权限体系和员工工作方式。AWS 的优势在于，它可以把云基础设施、Bedrock 和现场工程交付打包给客户。

第八条。DeepMind 前研究员转向量化交易。三名曾打造扑克 A I 的 DeepMind 前研究员创办 EquiLibre，把强化学习用于股票和加密市场交易，公司估值已超过五亿美元。他们认为扑克和金融市场都适合奖励驱动的自学习模型，因为结果信号清晰。EquiLibre 与 Tower Research Capital 合作，算法已处理每日数十亿美元交易量。这代表前沿 A I 人才正在离开大厂，进入能快速验证算法收益的垂直行业。

第九条。互联网之父 Vint Cerf 将退休。Vint Cerf 将卸任 Google 首席互联网布道师。他与 Robert Kahn 共同奠定 TCP/IP 协议，是现代互联网的重要奠基者。更值得关注的是，他在活动中谈到 A I 智能体未来需要互操作标准。他认为自然语言太模糊，不足以支撑多个智能体之间的精确协作。谁能定义 agent 通信、权限和任务协议，谁就可能在下一代网络结构中获得早期互联网协议制定者那样的影响力。

第十条。OpenClaw 登陆 iOS 与 Android。开源 A I agent 工具 OpenClaw 推出移动应用，用户可以通过手机连接 OpenClaw Gateway，调度自己的 agents 和相关工具。移动端意味着 agent 不再只是桌面或服务器里的开发者玩具，而开始进入日常任务入口。虽然 OpenClaw 早期传播中也伴随争议，但这次发布说明，agent 竞争正在走向手机、权限管理、工具路由和用户习惯。未来谁能成为随身智能体入口，谁就能拿到更高频的任务分发权。
